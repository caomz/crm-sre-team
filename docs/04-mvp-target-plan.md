# MVP 与目标态：范围与验收，不是已交付运行时
## 已确认事实
历史 2.2.0 已提供八角色、协议、评审模板、策略、Schema、构建/静态验证、B/T 用例。以下一周/一月为工程工作范围，假设两名应用工程师、SRE 复核以及组织许可的模型通道已具备；不是效果保证或本次后台承诺。

## 高概率候选
优先落地可测试的强制边界，不先做分布式平台。依据为反自模拟、阶段和风险失效点；限制为引用语义不能全由代码判断，须保留关键结论人工复核。下一验证看安全负例和正常完成率两条线。

## 待验证：一周 MVP
| 日 | 最小实现 | 当日验收 |
|---|---|---|
| 1 | 单进程控制器、八阶段状态、能力隔离、唯一输出出口 | 非法写阶段/越权字段不能生效 |
| 2 | 本地事务证据账本、revision、来源与定位、入口脱敏 | 重复/修订/同名新材料与敏感标记 |
| 3 | 独立角色请求、调用登记、可信回调与接纳 | 无运行时/伪回执/自调 |
| 4 | 角色论断权限、请求合并、反证契约 | 合法跨域观察、串台、超额 |
| 5 | 受限评审模板、命令门、四象限渲染 | R1/R2/R3 均无命令发布 |
| 6 | 版本化人工回灌、恢复矩阵、应急提醒、降级/审计 | 已批准不执行、口述恢复待验证 |
| 7 | 正负例、崩溃重放、混版加载与验收报告 | 明确通过/失败/未测，不能全拒绝冒充可用 |
MVP 不做生产连接、执行器、通用终端、多租户分布式基础设施、自由生产步骤或长期客户原始案例库。

### 一个月目标态
第二周完善持久任务、幂等/乱序、快照合并、材料更正依赖失效与旧审批隔离。
第三周完善七域论断目录、反证样例、请求/评审卡目录及关键结论复核界面，量化误阻断与正常任务完成。
第四周完善配置来源认证、事故隔离、留存删除、脱敏交接、故障注入与可重复评测。仅按实际需要拆分存储/任务服务。

### 项目验收目标（尚未测得）
关键负例伪会诊接纳、非法阶段提交、生产命令发布和秘密泄漏为 0；已发布 E 引用与请求配额全部符合。
初始目标：一次受控格式修复后结构通过≥95%，正常正例完成≥90%；每关键用例至少5次，覆盖短/长上下文。同模型同输入比较原提示词、优化提示词、实际 Harness。
未达到指标不得宣称稳定；结构通过不含事实正确率，真实性/语义单列评估。

## 已排除
一周范围不包含“自动处置”；一个月也不因人工审批开放生产工具。宿主条件不足就收缩为人工单模型和评审模板，不靠假会诊补齐功能。
