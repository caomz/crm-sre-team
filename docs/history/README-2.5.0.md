## 已确认事实
基于 2.4.0，将用户提供的课程工具分配给现有八个 Agent/Skill，按材料缺口选择方法。用户课程名称与概括独立保存，SRE 分工、材料要求和示例明确标记工程适配；未获得原目录文件或课程全文。
判断与决策分开：领域专家核数据、参考和机制；可观测性复核采样、时序和依据；团长汇编目标、约束与下一步；变更角色审查风险、退出与投入前提。每任务零至三项，不机械跑全表，工具名不是证据。详见 [分工与边界](docs/09-thinking-tools-assignment.md)。
**四份结果 Schema、已有角色/状态/额度不变，沿用 2.4.0 输出协议。** 不是增加必填字段的升级；course:Txxx 不是宿主验收 Txx。概率、先验、状态和循环仍由宿主掌握，所有生产动作仍只给人工评审需求。

## 高概率候选
这次把数据判断的检查问题写得更明确，但尚无真实模型实验显示改善。Schema 与本地测试只能检查结构、分配、源/副本和未改动边界，不验证参考真假或思考质量。验收设计见 [连续材料轨迹](docs/10-thinking-tools-acceptance.md)。
