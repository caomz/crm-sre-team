# 2.4.0 → 2.5.0 迁移说明
2026-09-22

## 已确认事实
本版新增思考工具分工、按材料触发的提示词、来源快照和静态验证。四份模型 Schema 字节保持原样，不增加必填字段或上下文；原 2.4.0 合法回包仍合法。非空更老版本回包的兼容问题仍按此前迁移说明，不宣称所有旧输出都会被拒绝。
发布版采用 2.5.0 表示新增判断分工功能，不代表输出协议破坏；既有 tests/harness-acceptance-cases.json 的 schema_version 有意保持 crm-sre-acceptance/v2.4.0，原验收用例、fixtures、测试源不改。
需整包替换以保持提示词、政策、参考、独立 Skill ZIP 和根版本锁一致。新增 policy 为声明性分工，不是宿主已执行的工具路由程序；不能只拷贝 JSON 就说运行时已支持。当前补丁只适用于 Agent 和 Skill 入口；旧补丁原路径或历史目录保留，不能直接套用于新文件。

## 高概率候选
升级后可用同样材料审查数据判断依据是否更充分；这是一项待模型实测的假设，不是迁移保证。

## 待验证
未新增主理人 settings、连接器或执行器。缺 Harness 的默认托管入口仍应受阻；人工入口显式独立选择。无候选启动、invalidated-only 重评、迟到结果接纳、目标变化后请求调整仍需宿主实现。运行时工具继承/授权未核验。
T028 只检查适用前提，不计算投入比例；T037 只借用可验证问题和判据，不新增数字概率或成绩。TT 为新测试设计，不冒充已执行的 B/T。

## 已排除
不是给模型增加 root、数据库、K8s 或 MCP 权限，不改变现有 Schema 约束、角色列表、阶段、请求配额或案例运行状态。此前文档已保存到 docs/history，历史数值不作本版验证结论。
