# Harness 工程建议稿（不覆盖用户的 02-harness-architecture.md）
## 已确认事实
本发行物已修改提示词/参考材料/模板并提供策略、Schema 和离线校验。下面的运行时架构尚未实现；不得因文件存在就宣称阶段、账本和输出门已生效。
系统始终是离线分析与人工评审支持，不包含生产执行器，不因为人工审批增加生产能力。

## 高概率候选：推荐组件
支持依据为原包的调用真实性、阶段、编号和门禁问题；反向限制是结构/回执不能保证语义正确；下一验证见 T01–T24。

```text
用户指定材料/人工回灌
  → 入口许可、敏感检查、受限解析
  → 证据账本与版本/来源/定位
  → 持久状态机与事件库
  → 当前任务上下文编译 + 路由/预算
  → 独立角色 Worker（无生产工具）
  → 可信调用回执 + 结构/角色/证据/时效验收
  → 团长引用已接纳论断汇编 + 请求去重
  → 风险卡门 + 唯一受限发布器
  → 四象限报告/评审卡/恢复与交接

任意诊断阶段 → 独立固定现场协同提醒（不推进阶段）
全路径 → 本地安全审计与 Harness 自身遥测
生产 SSH/数据库/K8s/监控/MCP：无连接，无执行适配器
```

| 模块 | 输入 | 输出 | 不变量 | 失效处理 |
|---|---|---|---|---|
| 入口与解析 | 指定上传、许可、事故 ID | 脱敏材料/隔离记录 | 不执行、不联网、不遍历；秘密不进模型 | 隔离，接受摘要 |
| 证据账本 | 材料、来源、时窗、定位 | E/revision/快照 | 唯一写者；材料身份与 blob/事件分开 | 不可写则不发布新引用 |
| 状态事件库 | 已验证用户事件与接纳结果 | 状态、合法任务 | 模型不能改 phase；状态/审计同事务 | 非法转换拒绝，并发重读 |
| 上下文编译 | 当前阶段、角色、read-set、反证 | 短任务包、input_digest | 独立控制面；摘要不替代原材料 | 超预算缩任务，不悄悄丢反证 |
| 路由与预算 | 指向、窄域任务、部署事实 | 1–3 专家任务或降级 | 禁自调、禁四人例外、K8s 双条件 | 无指向回初析；无能力降级 |
| 独立 Worker | task/role 配置/授权证据 | 原始结果与传输完成事件 | 独立上下文；无生产工具/跨成员直连 | 超时记缺席，不代写 |
| 来源验收 | DispatchRecord、可信 Completion | AcceptedResult | 身份/回执不来自模型正文 | 伪造、错任务、重复拒绝 |
| 论断与反证 | 结果、权限、引用 | 论断、候选、冲突 | 引用存在不等于支持；根因不自升 | 无法核对则待验证/人工复核 |
| 请求合并 | 各成员≤2提议、Q状态、预算 | 用户每轮≤3原子 Q | 只有此处可发布请求，继续不重置 | 去重/延期/拒绝材料包 |
| 风险卡门 | 目录动作、证据、前提、版本 | 齐备/缺前提卡 | 无执行器；无命令字段；未知不降风险 | 新动作人工定义 |
| 人工回灌 | 审批/执行/恢复/更正报告 | 版本绑定外部记录、恢复证据 | 报告不等于核实，审批不解锁 | 旧版本/未绑定报告不提升状态 |
| 唯一发布器 | 接纳论断、合法 Q、卡与状态 | 四象限、卡片、交接 | 无原始 token 旁路；署名/状态由代码 | 不合法退安全模板 |
| 审计遥测 | 状态/调用/拒绝/预算事件 | 安全审计、计数、trace | 不录秘密或完整材料；不接生产监控 | 关键审计失败阻断提交 |
| 降级控制 | 能力、错误、预算、无增益轮数 | TEAM/SERIAL/SINGLE/TEMPLATE/移交 | 降级只缩能力，不放宽规则 | 一次格式修复后明确降级 |

### 会话状态机
P0 分类 → P1 初析 → P2 最小取证 → P3 专家分析 → P4 收敛 → P5 人工评审 → P6 回灌验证 → P7 交接。
P4 可回 P2/P3；P6 可回 P2/P3/P4；P2 不直达 P5。P2 缺材料可经显式受限分析理由到 P3，不要求全部潜在材料齐备。
phase_status 独立为 READY/RUNNING/WAITING_INPUT/BLOCKED。无法继续时可在任何阶段生成受阻交接并结束会话，不冒充正常 P7 完成，不关闭业务事故。
任意阶段接收人工报告、发布应急提醒，但不由此跳阶段。非事故任务的不适用环节须有理由记录。

### 证据账本与版本
Evidence：incident_id、evidence_id、source_kind、object_alias、event_window、collected_at、timezone、source_group_id。
EvidenceRevision：revision、脱敏 blob 哈希、locator、limitations、supersedes；Claim/Candidate 引用具体版本。
同材料重复复用 E；更正保留 E 增版本；不同采集事件不因字节相同合并；内容哈希不代表独立证据。更正触发依赖失效/重评，旧引用可定位但不可继续当有效材料。
秘密不入正式账本；留存删除是受控事件，不以不可变日志无限保留原文。

### 真实调用证明
DispatchRecord 由宿主创建 task_id、agent_id、attempt_id、epoch、snapshot、role_hash、input_digest。
CompletionEnvelope 由可信模型适配器产生 transport_request_id、task_id、attempt_id、output_digest、completed_at。模型只回显 task_id，不掌握签名密钥，不自报权威回执。
验收来源是独立可信返回通道及已登记任务，不是文本中的成员名。MVP 单进程受控回调；多进程目标态再增加认证、防重放。真实调用不证明认知独立或结论正确。

### 并发、持久化与恢复
state_revision 用于写入冲突，analysis_epoch 与 evidence read-set 判结果时效。同快照兄弟结果不因其他提交被误拒；新 epoch 的迟到结果隔离或复核。
事件、状态、待发布项同事务；材料/Q/任务/用户消息有幂等键。允许远端重复调用，但每个逻辑任务只接纳有效一次、用户请求不重复发布。
恢复维度 technical/online_business/backlog/data_correctness 与 rca_state 独立。报告只是 USER_REPORTED；关键恢复/因果确认需要足够证据及人工/可核规则复核。

### 风险与发布
所有生产动作只评审卡；既有许可、只读、可回退、审批完成都不提供命令。目录仅预审文本和受限字段，未知类别由人工定义；自由文本黑名单无法作绝对保证。
动作 ID/revision、advice_state、approval_report、execution_report、outcome_evidence 分开；没有执行器或批准后运行接口。审批真实性离线不可核时保留来源归属。
四象限必须齐全；候选有支持/反证/可证伪条件/替代解释/下一验证，已排除有范围。结构、权限和语义三层验收，JSON 合法不能替代证据语义。

### 用户回灌与遥测
本地应用可定义 evidence、feedback、request-responses、report、handoff 资源。Feedback 使用 client_message_id 幂等、绑定 action_id/revision；旧审批不适配新范围，未绑定报告暂存而不提升状态。
记录实际调用/接纳/缺席、非法转换、无效引用、跨事故引用、过期结果、请求超额、命令门拦截、敏感信息处理、Schema 首次通过、修复次数、延迟/token 和正常任务完成率。不得把 Harness 自身遥测扩成生产监控接入。
默认本地安全计数，不保存原始提示词、客户日志、秘密或完整模型输出。关键审计失败不提交权威结果。

## 待验证
MVP 可单进程加本地 SQLite；十四项是逻辑边界，不必拆十四服务。目标态按并发和隔离需要扩展，不能为了架构完整引入生产接入。
正常完成率、引用语义、角色误伤、注入/秘密漏检及宿主发布旁路均需实测。本包只有静态/契约测试，不含此运行时实现。
