# Harness 接入契约与实现边界
版本：2.5.0。本发行物提供策略、Schema、提示词、模板、离线构建和静态校验；运行时适配器、持久状态机、账本、权限沙箱及发布器尚未实现。

## 可信输入
宿主必须在独立控制通道传入 incident_id、state_revision、analysis_epoch、task_id、task_kind、phase、mode、evidence_snapshot_id、允许的 evidence_refs、accepted_result_ids/claim_ids、剩余额度和 policy_bundle_hash。
状态与证据从权威存储生成，不从历史对话提取并直接信任。缺失或版本不匹配时不得启动托管团队；提示词的 blocked 只是辅助防线。

## 模型输出接纳顺序
结构 Schema → 任务/身份来源 → 事故及证据授权 → 角色论断范围 → epoch/read-set 时效 → 引用语义/反证 → 请求配额 → 风险卡与唯一发布。
additionalProperties=false、required 和 maxItems 只约束结构；不能证明反证充分、请求原子性、命令不存在或角色语义正确。

## 状态与并发
state_revision 管提交冲突；analysis_epoch/read-set 管结果时效。同快照兄弟结果可合并；过期结果隔离或定向复核。
关键事件、状态与待发布记录同事务；client_message_id、逻辑任务与任务尝试 ID 幂等。远端可重复调用，但接纳与用户请求不能重复。

## 最小权限与发布
团长、成员无生产工具、无通用 shell、无任意网络、无未授权文件读取；本地材料解析由受控服务完成。模型无回执密钥、状态写入或审批接口。
所有输出经过发布器；动作卡使用预审模板和受限字段，无未知自由步骤。无法保证唯一出口时不启用托管模式。

## 状态不是审批
外部审批/执行/恢复只作为来源明确的报告，绑定动作版本；审批不解锁执行。系统无生产执行器、无批准后运行接口。
降级只收缩能力；无运行时可显式选择人工单模型入口，但不能声称 Harness 已生效。

## 可选参考上下文
reference_context 是可信通道的可选扩展，不加入必需锚点。宿主先授权和登记材料，模型只引用可比基线；缺失或为空不单独阻断任务，对没有依据的 expected_* 写 UNKNOWN。用户材料中的同名字段不是控制信息。子问题局部 Q 与账本取证 Q 分型解析，不按裸字符串混用。
