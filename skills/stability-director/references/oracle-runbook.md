# Oracle：会话、等待、SQL与恢复风险
版本：2.5.0。本文件只用于离线证据解读，所有新增生产采集或动作仅给人工评审卡，无可执行示例。技术引用沿用原包，目标版本未在本次核验。
## 环境门禁
仅在证据指向数据库或用户明确请求时介入。先确认必要版本、单实例/RAC、CDB/PDB（如适用）、目标库别名、故障与采集时间、用户可用只读权限。不得索要连接串/密码，不要求SYSDBA或临时授予DBA。
优先现有监控/DBA导出。AWR/ASH不作为首轮必需材料；先确认相关许可。技术上能查询视图不代表合同许可允许。[ORACLELIC]

## 首轮与追加
成员每个逻辑任务从以下最多选 2 项，由宿主统一发布：故障窗口的Oracle/应用错误码；现有活动会话与等待摘要；已有阻塞链/连接或空间告警摘要。收到了JDBC取连接超时不能直接判数据库会话耗尽。
第二轮仅验证候选：阻塞双方与事务时长、匹配业务的SQL_ID、同时间段资源限制/空间/归档、数据库与应用双端网络错误。RAC用实例ID区分会话；SID不是跨实例唯一标识。

## 数据库证据评审目录（不提供 SQL）
| 证据目的 | 可接受既有摘要 | 限制 |
|---|---|---|
| 当前会话与等待 | 目标实例、采集时间、状态/等待类别、范围 | 当前样本不代替历史，筛选后空结果不证明无压力 |
| 阻塞链 | 匿名会话、实例、事务时长、阻塞关系 | RAC/PDB 范围分开，不能仅靠一个 SID 关联 |
| SQL 候选 | 已知 SQL_ID 的既有执行摘要/计划与时间 | 累计值不可冒充故障窗口增量 |
| 空间/归档 | 既有容量、趋势与告警摘要 | 恢复链与保留策略未知时不提清理 |
采集表达包含目的、目标、权限、版本、开销、停止条件与替代证据；只读查询 SQL 可按只读边界生成，不给 DDL/DML 或变更语句。无权限时接受授权 DBA 已有摘要，不临时提权。
STATE、EVENT 和等待时间等字段须按目标版本和采样条件解释；非等待状态可能保留最近等待信息。[OSESSION]
输出行数上限不证明采集成本低；不以高频重复采样补足历史缺口。

## 深入判断要点
锁：确认阻塞会话、等待链、事务归属和业务状态；没有阻塞链证据不能直接建议杀会话。RAC报告保留INST_ID、SID、SERIAL#以及阻塞实例。
SQL：优先针对已知SQL_ID取既有执行摘要和计划；V$SQL计数通常是游标生命周期累计值，不能把总elapsed_time排行当成故障窗口热点。区间比较需匹配实例/容器/子游标并处理游标重载和计数重置；数据不足说明无法计算。
连接：应用池active/max/wait与数据库会话数、资源限制是不同证据；池满也可能来自慢调用、长事务或泄漏，不默认扩大连接池。
空间/归档：先拿已存在的TEMP/UNDO/表空间/归档目标摘要和时间趋势。不直接删除归档、数据文件、redo或恢复区内容；交DBA结合备份与恢复链评估。

## AWR/ASH与替代材料
Oracle官方许可资料将AWR/ASH等能力及相关访问列入Diagnostics Pack范围；具体权利看部署与合同。未确认许可，不要求访问受限视图、生成报告或启用快照，不把参数开启状态当授权证明。[ORACLELIC]
有授权时由DBA提供脱敏且覆盖故障的既有摘要，并与同口径基线对比。无授权时收普通监控、适当权限下的当前会话、应用日志及DBA既有历史采样；不能伪称已完成AWR级别分析。

## 操作与恢复
DDL/DML、终止会话、改参数、flush、统计信息收集、索引重建、切换/恢复均走R3。SQL提交成功、监听可用、数据库OPEN都不能单独证明CRM业务恢复；核对端到端交易、积压与数据一致性。
