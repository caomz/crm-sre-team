# P0–P7：唯一八阶段状态契约
版本：2.5.0。阶段是代码状态，不是模型对话中的标签。phase_status 独立为 READY/RUNNING/WAITING_INPUT/BLOCKED。

| 阶段 | 允许产物 | 离开守卫与合法去向 |
|---|---|---|
| P0 接报分类 | 任务类型、已知业务影响、组织分级缺口 | 分类完成，未知有记录 → P1 |
| P1 初析 | 已有材料质量、最小证据计划、路由建议 | 计划形成 → P2 |
| P2 最小取证 | 过配额与风险检查的 Q、质量检查、不可获得记录 | 有限材料已可分析或有理由接受受限分析 → P3；否则等待/受阻 |
| P3 专家分析 | 真实接纳结果或明确缺席/降级记录 | 本批结束并记录限制 → P4 |
| P4 候选收敛 | 排序、反证、冲突、关键替代解释 | 补证 → P2；定向分析 → P3；评审材料形成 → P5 |
| P5 人工方案 | 人工评审卡或缺前提卡 | 等待外部结果 → P6；无需动作记 NO_ACTION_REQUIRED |
| P6 回传验证 | 技术、在线业务、积压、正确性与副作用 | 缺证 → P2；需分析 → P3/P4；可交接 → P7 |
| P7 交接复盘 | 结论边界、证据索引、遗留项和责任人 | 会话结束；新事件重开调查必须由宿主记录原因 |

## 不能被模型改写的守卫
不接受模型 next_phase。P2 已有材料足够时可以零新增请求通过，但需记录证据覆盖与理由；不能以“应急”为由 P2 直接进入普通 P5。
P3 真实多 Agent 不可用时，宿主只能选择 SERIAL/SINGLE/TEMPLATE 并标识；团长不能代写成员结果。
P4 不按多数票、不二选一、不以时间重合确立因果。成员是论断来源，不是确认依据。
非事故评审任务可对不适用环节记录 NOT_APPLICABLE 与理由，阶段事件仍可追溯；评审完成不是事故恢复。

## 独立应急与外部事件
任意阶段持续重大影响都可发布固定现场协同提醒，不改变诊断 phase，不要求等待材料，不给执行步骤。
任意阶段接收审批、执行和恢复报告；报告立即保存为外部陈述，不自动跳阶段或确认结果。
业务分级采用组织规则，未知保持未知；告警数量不是分级依据。

## 并发、重放与上下文
state_revision 用于提交并发控制，analysis_epoch 与 evidence_snapshot/read-set 用于结果时效。相同快照的兄弟结果不因全局 revision 增长而互斥。
关键状态、事件和待发布记录同事务保存，用户回灌、材料登记、Q 发布、任务接纳均须幂等。远端模型调用可重复，但结果只接纳一次；不得承诺调用 exactly-once。
每次从持久状态编译当前任务短上下文，保留必要反证与材料限制；历史摘要不能成为更高权限状态源。

## 恢复与关闭
独立维护技术、在线业务、积压、数据正确性、RCA。人工一句恢复、进程正常、端口可用不够完成验证。
观察窗口、分母口径与通过标准依据组织基线确认，不能使用统一分钟数。在线恢复但积压未清保持业务清理未完成。
结束 AI 会话、移交 RCA、业务事故关闭是三个不同动作；根因未知可以移交，业务事故关闭须相应恢复证据及人工记录。
十步约束映射：影响 P0，证据登记贯穿，路由 P1/P3，真实调用 P3，四象限 P4，请求合并 P2/P4，应急独立，风险 P5，恢复/RCA P6，交接 P7。
