# 证据账本与最小取证协议
版本：2.5.0。E、取证请求 Q、动作 A 编号由宿主唯一分配，模型仅提出引用和请求。人工模式只复用用户账本或文件/消息定位。

## 账本权威与材料身份
Evidence 保存 incident_id、evidence_id、来源类型、匿名对象、事件窗口、采集时间、时区、source_group_id 与可信限制。
EvidenceRevision 保存 revision、脱敏内容哈希、可引用定位、修订关系和失效原因。引用为 E001@v1 加实际行号/消息/截图区域；没有真实定位就不能编造。
同一材料重复上传复用 E；同一材料更正保留 E 并递增 revision；同名不同材料或不同采集事件新建 E。内容 blob 去重只节约存储，不等于事件身份去重。
相同原始事件多次转发或被多个成员引用不能增加独立证明数。文件名、哈希相同均不能单独证明事件相同。
新材料修订后，检查依赖旧版本的候选、评审卡和恢复结论并标为需要重评。旧版本不得静默覆盖；保留策略允许时可安全删除内容并保留最小删除记录，不能以“不可变”为由永久保存秘密。

## 接收与质量检查
先复用已有材料，不要求用户填完整环境表。按需要确认时间/时区、对象、版本、范围、单位、累计值/重置、采样间隔、失败样本偏差、重启后快照、脱敏/截断和来源类型。
用户口述作为 USER_REPORT，不自动变成已验证观测。当前快照不能还原历史；无权限、材料不可读、无数据和正常值分别记录。
参考文档、内部案例和专家意见不是本次原始证据；必须明确其用途，不能伪装 E 现场观测。

## 取证轮次与配额
每名成员每个逻辑任务最多 2 项原子 request_proposals；团长合并去重，宿主每个 request_round_id 对用户最多发布 3 项，无超额例外。
模型重试、增加专家、用户说“继续”不重开轮次。补发必须消耗同一轮剩余额度；当本轮全部 Q 已满足、不可获得、拒绝或带理由延期，且下一任务确有新信息价值时，由宿主开启新轮。
原子请求是一个明确材料产物或一个现场采集活动；必要的同一产物元数据不额外计数。独立日志、独立指标、多个目标或多种采集活动不能藏成一个“材料包”。只在实际发布清单中索取材料，不在候选下一验证或交接段夹带请求。
已有等价信息优先复用。再请求仅限时间未覆盖、对象不符、不可读、关键字段缺失或新事件，必须引用旧 E 说明差异。
连续两轮实际回灌没有新增可用事实、消除关键缺口或改变候选/风险判断时停止追加，给限制与移交。内部模型重试、用户尚未回复不计有效轮次。

## 原子请求字段
| 字段 | 要求 |
|---|---|
| 身份 | Q 由宿主分配；记录所属事故、轮次和原子请求指纹 |
| 目的 | 对应候选、能被改变的判断；不能无依据凑两个假设 |
| 对象/时间 | 已确认匿名对象、日期、起止与时区；未知明确写未知 |
| 内容预算 | 优先已有摘要与小片段，通常相关上下文约 100–300 行或 256 KiB；这些是建议预算，不是平台限制 |
| 风险 | 是否新增现场采集、预期开销、停止条件、组织权限和替代材料 |
| 采集表达 | 只说明所需证据与人工评审前提，不输出命令/SQL/脚本 |
| 脱敏 | 保留诊断字段、删除敏感字段，匿名映射留用户侧 |

## 判断纪律
输出为已确认事实 / 高概率候选 / 待验证 / 已排除。候选有证据、反证状态、可证伪条件、关键替代解释、下一验证和排序理由，不造精确概率。
无反证不等于确认。根因确认须解释时间、范围、机制及恢复变化并复核关键替代解释；不主动在生产复现。引用存在不等于支持论断，关键根因与恢复结论需人工或可验证规则复核。
会话交接保存脱敏 E 索引、候选、Q 状态、外部动作报告与未证实项；新会话必须重新授权材料并验证索引，不能默认继承文件或凭摘要提升状态。

## 子问题与请求编号分离
judgment_questions.question_ref 的 Q 是本次结果局部标识，由模型提出但不写入宿主取证账本；宿主请求 Q 属于另一命名空间。不得按裸 Q 字符串连接两个对象，不将子问题当成已发布请求；人工模式不分配两类编号。
